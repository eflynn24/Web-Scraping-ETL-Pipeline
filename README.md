# Web Scraping & LLM Data Pipeline

Build an end-to-end ETL pipeline that collects website data, extracts and cleans text, applies data quality filtering, and prepares structured datasets for **large language model (LLM) training and evaluation**.

## Pipeline Objectives

The pipeline is designed to:

1. **Ingest** web data from Common Crawl
2. **Extract** relevant content and metadata
3. **Clean and normalize** extracted text
4. **Evaluate and filter** documents using quality criteria
5. **Construct** structured datasets for downstream use
6. **Analyze** dataset quality and composition
7. **Prepare** LLM-ready training and evaluation datasets
